## Security (3 / 10)

### Landmines

1. **XSS via `v-html` on received email HTML** (CRITICAL)
   - `apps/crm/src/components/CommunicationThreadView.vue:401,417` — renders inbound email HTML unsanitised
   - `apps/crm/src/views/communications/ComposeView.vue:645–647` — renders header/body/footer in preview
   - `apps/crm/src/views/communications/CampaignDetailView.vue:611` — campaign body
   - `apps/crm/src/views/settings/EmailSignaturesPanel.vue:132,173,235,269` — user-editable signatures
   - **Fix:** [`01-xss-sanitize-html.md`](./01-xss-sanitize-html.md)

2. **localStorage JWT + client-only logout** (CRITICAL)
   - `packages/api-client/src/http.ts:8` — token in `localStorage.getItem('torny.token')`
   - `apps/crm/src/stores/auth.ts:82` — logout only clears storage, no server-side revocation
   - **Fix:** needs a backend brief for HttpOnly session cookies. Deferred.

3. **No Content-Security-Policy headers** (HIGH)
   - Azure SWA (`apps/crm/public/staticwebapp.config.json`) sets `X-Frame-Options: DENY` and `Referrer-Policy` but no CSP
   - Nuxt configs have no security headers
   - **Fix:** deserves its own PR — risks breaking Stripe / fonts.

4. **No dependency vulnerability scanning** (MEDIUM)
   - No `.github/dependabot.yml`, no `renovate.json`
   - No `pnpm audit` in CI
   - **Fix:** 20-min Dependabot config. Queued.

### Not landmines

- `.gitignore` correctly excludes `.env*`
- CI secrets properly referenced via `${{ secrets.X }}`
- No hardcoded Stripe/AWS keys in source
- Only one hardcoded dev secret: `apps/club-sites/.env` `NUXT_REVALIDATE_SECRET` (dev-only per `.env.example`)

## Observability (2 / 10)

- No Sentry, Bugsnag, Rollbar, Datadog, or Honeybadger — searched every `package.json` and source tree
- No product analytics (PostHog, Mixpanel, etc.)
- No RUM, no `web-vitals`, no Sentry performance
- No `X-Request-ID` / correlation ID in `packages/api-client/src/http.ts`
- Only 4 `console.*` calls in prod code — discipline is good, but there's no aggregation layer either
- Feature flag infra: hardcoded per-plan gating via `apps/crm/src/composables/usePermissions.ts`; no gradual rollout

**Impact:** You cannot answer "is prod broken right now?" or "which feature do users actually use?"

## Deployment & ops (4 / 10)

- **CRM** auto-deploys to Azure SWA on push to `main` (`.github/workflows/crm-azure-swa.yml`)
- **club-sites** deploys manually via `pnpm deploy` (Wrangler, from a laptop)
- **torny-web** deployment is unclear
- No staging environment
- No PR preview deploys
- No `CHANGELOG.md`, no git tags, all `package.json` versions are `0.0.1`
- No rollback runbook (platforms support it, but no documented process)
- README + CLAUDE.md are excellent for developers; nothing for ops / incident response

## Accessibility (4 / 10)

### What's good

- `TornySelect` / `TornyMultiSelect` have real keyboard nav (arrow keys, home/end, type-to-jump, escape)
- `CrmModal` has `role="dialog"`, `aria-modal="true"`, Escape dismissal, body scroll lock
- No `tabindex > 0` abuse, click handlers paired with keydown
- Landmark roles present in all layout shells

### What fails WCAG AA

- **Sign-in errors silent to screen readers.** `apps/crm/src/views/auth/SignInView.vue:132` — error div has no `aria-live`, inputs have no `aria-describedby`, no `aria-invalid`
- **Accept-invite form same problem.** `AcceptInviteView.vue:230,251`
- `TornyMultiSelect.vue:189` — `activeIndex` computed but `aria-activedescendant` not bound
- No skip-link to main content in `CrmShell.vue`
- No a11y tooling (no `@axe-core/playwright`, no `eslint-plugin-vuejs-accessibility`)
- No WCAG AA verification on design tokens (OPEN RATE regression was caught by console-error policy, not contrast tooling)

---

## Compliance (3 / 10)

### Gaps

- **No GDPR DSR flow.** No "export my data", no "delete account" route
- **No actual `/privacy` or `/terms` page.** Convention + link target exist; no default implementation
- **No cookie consent library.** `cookieBanner` is a boolean in site settings but not wired to a consent callback
- **No audit logging** visible for PII access / changes
- **No RFC 8058 List-Unsubscribe header** evident in email sends

### What's good

- Stripe integration: no card data ever touches Torny (checkout redirect model)
- Email masking in `members` API for committee callers (owner/admin get raw)
- Unsubscribe tracking in `communications` model + public endpoint

## i18n / market reach (2 / 10)

- **`'en-NZ'` hardcoded in 25+ files** across `apps/crm`, `apps/club-sites`, `packages/content-blocks`
- No i18n library
- Currency always `"$"` (NZD implied)
- No timezone support
- `TournamentSearchBlock.vue` copy says "Every open tournament across NZ"

**Impact:** AU/UK launch requires a refactor, not a config flip.

## Performance (7.5 / 10)

### Good

- All 50+ CRM routes lazy-loaded (`() => import(...)`)
- No heavy deps — no moment, no lodash, no d3
- 100% scoped CSS
- `apps/club-sites` uses Cloudflare Pages + Nitro, SWR caching correctly disabled for multi-tenant

### Quick wins

- 10 `<img>` tags in content-blocks missing `loading="lazy"` on avatars
- No Vite manual chunking in `apps/crm/vite.config.ts`
- No `@nuxt/image` on either Nuxt app
- Google Fonts imported without `preconnect`
- `MemberDetailView.vue` loads 200 members into memory — needs cursor pagination

## Testing (6 / 10)

- **Unit tests:** 9 files. 7 in CRM `__tests__/`, 2 in torny-web
- **E2E tests:** 16 files. 15 in CRM Playwright, 1 in torny-web
- **Package tests:** 0 — `api-client`, `content-blocks`, `design-tokens` are untested
- Mocking: hand-rolled `vi.fn()` on `globalThis.fetch`. No MSW
- Smoke test strictly fails on un-whitelisted `console.error` — caught the OPEN RATE regression
- No `.only`, no `.todo`, 2 conditional `.skip`s for external services

**Coverage estimate:** ~6–8% unit by file count. Store/view tests effectively zero.

## Strengths worth keeping

- `strict` + `noUncheckedIndexedAccess` + `noImplicitOverride` at the TS base
- 4 `as any` casts in the whole CRM, all for CSS custom properties
- Brief-driven error codes in `api-client` — FE switches on `err.code`, doesn't invent
- `TornySelect` / `TornyMultiSelect` are generic over `T`; native `<select>` genuinely absent
- Console-error gating on smoke tests
- Store hygiene: optimistic updates with revert, abort controllers on club-flip, stale-response guards

## Methodology notes

Six parallel scans by `Explore` agent, each reporting evidence with file:line citations. Synthesised from source inspection only — no runtime measurement, no live network capture, no dependency audit run. Numbers are judgement calls on a 10-point scale with examples; treat as relative rather than absolute.
